# Syntax & Semantics
- Syntax: the rules which tell us how the well formed sentences are constructed.
	- which are the symbols used to represent propositions, variables, functions, predicates and 
	- which are the symbols used to represent connectives … 
	- In order to obtain well formed formulas
- Semantics: the rules which tell us the _meaning_ of the well formed sentences. 
	- two main realms: 
		- Model theory: what is true 
		- Proof theory: what is provable 

# Propositional Logic
Propositional logic is the simplest logic- illustrates basic ideas using ___propositions___. 
Example:
- P1 Snow is white 
- P2 Today it is raining 
- P3 This course is boring

$P_i$ is an atom or atomic formula. Each $P_i$ can be either true or false but never both.
The values true or false assigned to each proposition is called ___truth value___ of the proposition.

# Semantics of propositional logic

## Interpretation 

> [!Definition]
> Given a propositional formula $G$, let ${A_1, ..., A_n}$ be the set of atoms which occur in the formula, an ___Interpretation___ $I$ of $G$ is an assignment of truth values to ${A_1, ..., A_n}$.   

Given an interpretation $I$, a formula $G$ is said to be true in $I$ iff $G$ is evaluated to ___True___ in the interpretation. 
Given a formula $G$ with $n$ distinct atoms, there will be $2^n$ distinct interpretations for the atoms in $G$.  

> [!WARNING]
> There is an important __convention__: $\{P, ¬Q, ¬R, S\}$ represents the interpretantion $I: \{P = T, Q = F, R = F, S = T\}$. 

 Given a formula G and an interpretation $I$, if $G$ is true under $I$, we say that $I$ is a ___model___ for $G$, and we can write $I \models G$.

## Validity
A formula F is ___valid___ iff it is _true_ in all its interpretation.
- A valid formula is also called a ___Tautology___.
- A formula which is not valid is _invalid_. 
- If $F$ is valid we can write $\models F$.
![[de_morgan_law.png]]

## Inconsistency
A formual $F$ is ___inconsistent___ iff it is _false_ in all its interpretation. 
- An inconsistent formula is said to be ___unsatisfiable___.
- A formula which is not inconsistent is ___consistent___ or ___satisfiable___.

> [!WARNING]
> ___Invalid___ is <span style="color:red">different</span> from ___inconsistent___!
> 
> But, invalid == consistent. 

![[inconsistent_example.png]]

## Inconsistency vs. validity
- A formula is valid iff its negation is inconsistent (and viceversa)
- ==A formula is invalid (___consistent___) iff there is at least an interpretation in which the formula is false==. 
- An inconsistent formula is invalid but the opposite is not true (an invalid formula is not always inconsistent). 
- A valid formula is consistent but the opposite is not true. 

To sum up: 
- Valid(X) -> Consistent(X) 
- Incosistent(X) -> Invalid(X)
- Invalid(X) <-> Consistent(X) 

# Decidability

Given a set of axioms $AX$ which describe some "world", consider a formula $F$. We are interested in the following questions:
1. $AX \models F$?
	- Meaning, is $AX$ a logical consequence of $F$?
2. $\models F$?
	- Is $F$ valid?
3. Is $F$ satisfiable?
	- Is there an $I$ such that $I \models F$? 

It is important to know wheter we can answer "yes or no" to these questions. Essentially, it is important to know whether these problems are ___decidable___.

>[!Property]
>Propositional Logic is ___decidable___. There is a terminating method to decide wheter a formula is _valid_.
>

To decide whether a formula is valid:
1. We can enumerate all possible interpretations. 
2. For each interpretation, evaluate the formula.

The number of interpretations for a formula are finite ($2^n$). Usually, there's a tradeoff between _representational power_ and _decidability_.

## Logical equivalence

> [!Definition]
> Logical equivalence: two formulas $F$ and $G$ are ___logically equivalent___ ($F \equiv G$) iff the truth values of $F$ and $G$ are the same under every interpretation of $F$ and $G$.

## Normal forms
Main normal forms:
 - Conjunctive Normal Form (CNF)
 - Disjunctive Normal Form (DNF)
 - Negation Normal Form (NFF)
	 - iff negations appear _only_ in front of atoms. 

> [!Literal]
> A literal is an atom or the negation of an atom.

## CNF

> [!defintion]
> $F$ $\in$ CNF iff: 
> - it is in NNF 
> - has the form $F \doteq F_1 \land F_2 \land .... \land F_n$ where each $F_i$ is a disjunction of literals. 

If $F$ is in CNF each $F_i$ is called a ___clause___. ==CNF is also referred to as the clausal form==.  

## DNF
> [!defintion]
> $F$ $\in$ DNF iff: 
> - it is in NNF 
> - has the form $F \doteq F_1 \lor F_2 \lor .... \lor F_n$ where each $F_i$ is a conjuction of literals. 

# Logical consequence
Given a set of formulas $\{F_1, ..., F_n\}$ and a formula $G$, $G$ is said to be a logical consequence of $F_1,...F_n$ iff for any interpretations $I$ in which ==$F_1 \land .... \land F_n$ is true, $G$ is also true==. 

- If G is a logical consequence of $\{F_1, ..., F_n\}$ we write $(F_1 \land .... \land F_n) \models G$. 
- $F_1, ...., F_n$ are called axioms or premises for $G$.
- $F \equiv Q$ iff $F \models Q$ and $Q \models F$. 
- S -> C and C -> F, then S -> F

## Deduciton theorem
Given a set of formulas $\{F_1, ..., F_n\}$ and a formula $G$, 
$(F_1 \land .... \land F_n) \models G$ iff $\models (F_1 \land .... \land F_n) \rightarrow G$.
(that is, $(F_1 \land .... \land F_n) \rightarrow G$ is always true). 

## Refutation
Given a set of formulas $\{F_1, ..., F_n\}$ and a formula $G$, 
$(F_1 \land .... \land F_n) \models G$ iff $\models (F_1 \land .... \land F_n \land ¬G)$ is inconsistent. 
(that is, $(F_1 \land .... \land F_n) \rightarrow G$ is always false). 

### Example
We want to prove $(P \rightarrow Q) \land P \models Q$. That is, each interpretations in which $(P \rightarrow Q) \land P$ is true, $Q$ is also true.

# Proof theory (natural deduction)

Yes, through __proof theory__.

In natural deduction, we consider only the connectives $\land, \rightarrow, \bot$. 
We don't consider $\lor$ since it has a quite different meaning in constructive and non-constructive approaches.
