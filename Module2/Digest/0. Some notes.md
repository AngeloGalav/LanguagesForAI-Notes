# Symbolic computation (expert systems)
Symbolic computation is:
- Logic based reasoning 
- Can provide explanations for decisions 
- Not appropriate for problems such as image recognition (cannot be solved algorithmically)

Sub-symbolic computation is:
- Based on (artificial) neural networks and ML 
- Very good for image recognition and many problems which cannot be solved algorithmically 
- Cannot provide explanations for decisions (thus far away from passing the Turing test!)
