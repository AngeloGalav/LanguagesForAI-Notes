In LP, programs are formulas. 

What is new for logic programming languages is that computation is exactly the same as logic deduction (resolution). This allows to prove properties of programs (e.g. correctness) in a much more easy way.

Logic programming languages are declarative languages, ==in the sense the the programmer specifies the ”what”==, while the machine takes care of the ”how”.

# Syntax (EBNF)
The Syntax of LP is defined using the extended Backus-Naur form. 
$$Name: G, H ::= A | B, Condition
$$
- Name: name of the rule
- Capital Letters: syntactic entities
- G, H: defined entities. 
- if _Condition_ holds, then G and H can be of the form A or B. 

# Semantics
State transition systems (also called ___refined calculus___).
- _State transition_ systems provide the ==operational== (also called procedural) semantics: this defines how the computation evolves.
- As previously mentioned computation is deduction (resolution): we will use state transition systems to describe resolution steps. 

## (Simple) State Transition System
A Simple State Transition System (in the following Transition System or TS for brevity) is a pair (S, ->) where 
- S set of states 
- '->' binary relation over states: transition relation 
- (state) transition from S1 to S2 possible if (some given) condition holds, i.e. S1 and S2 are in relation ->, written S1 -> S2
- There are some distinghuished subsets of S: the initial and final states. 
- ->\* is the reflexive-transitive closure of ->.  

==Reduction is synonym for transition==.

# Refined Calculus
Intuitively a refined calculus is a first order language, provided with a ___congruence___ (==which is used to factorize equivalent formulas and thus reduce the number of rules==, see next chap.) and a transition system which <u>defines the calculus rules</u> (i.e. the operational semantics).

For this reason, a Refined Calculus is defined by a Triple $(\Sigma, \equiv,T)$ where:
- $\Sigma$ is a signature for a first-order logic language
- $\equiv$ is a congruence (equivalence relation) on states
- $T = (S, \rightarrow)$ is a transition system, where a state $s \in S$ represents a logical expression over the signature $\Sigma$. 

### Congruence
- A congruence is used to identify states which are considered _equivalent_ for purpose of computation. 
- congruence instead of modeling with additional transition rules
- formally, congruence is an equivalence relation compatible with the structure:
	- (Reflexivity) 
	- (Symmetry) ($A \equiv B \iff B \equiv A$)
	- (Transitivity) ($A \equiv B \land B \equiv C \iff A \equiv C$)
