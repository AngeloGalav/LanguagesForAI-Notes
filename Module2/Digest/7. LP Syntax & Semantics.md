
# Syntax
- ___Goal___ (or query): 
	- empty goal $\top$ (top) or $\bot$ (bottom), or 
	- atom, or 
	- conjunction of goals
- (___Horn___) clause: A <- G
	- head A: atom
	- body G: goal
- Naming convention:
	- fact: clause of form A <- $\top$ 
	- rule: all others

A logic program is a finite set of Horn clauses. 

Note: that a Horn clause is a clause with at most one positive literal(??)

Essentially, the call 
```
path(a,X)
```
will return the "value" of X (that is, the node with a path from a).
