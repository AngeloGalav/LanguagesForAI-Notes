First Order Logic takes Propositional logics and adds the existential and universal operators.

# FOL Syntax
Signature $Σ = (P, F)$ of a first-order language:
- $P$ is a finite set of predicate symbols, each with arity $n \in N$
- $F$ is a finite set of function symbols, each with arity $n \in N$

Naming conventions: 
- nullary, unary, binary, ternary for arities 0, 1, 2, 3 
- constants: ___nullary function symbols___
- propositions: ___nullary predicate symbols___

![[fol_alphabet.png]]

A term is:
- a variable from $V$
- a funciton term $f(t)$ where $f$ is an $n$-ary function symbol form $\Sigma$ and the argument(s) $t$ ==are terms== $(n \ge 0)$. 

The set of terms is written as $T(\Sigma, V)$. 

## Well-formed Formula
Set of well-formed formulas $F(\Sigma, V) = {A, B, C, ..., F, G, ...}$:
- an atomic formula $p(t)$, where $p$ is an n-ary predicate symbol from $\Sigma$ and the arguments $t$ are: 
	- terms 
	- $\bot$
	- $\top$
	- $t_1 \doteq t_2$ for 
- the negation, disjunction, conjuction of a formula $F$.
- An universally quantified formula $\forall XF$, or an existentially quantified formula $\exists X F$, where $X$ is a variable and $F$ is a formula.

# Semantics of First-Order Logic

Interpretation I of Σ, consists of: 
- A universe $U$, that is a non-empty set. 
- A function $I(f): U^n \rightarrow U$ for every n-ary function symbol $f$ of $\Sigma$
- A relation $I(p) \subseteq U^n$ every n-ary function sybol $p$ of $\Sigma$

___Variable Valuation___ for $V$ with respect to $I$:
- $\eta : V \rightarrow U$ for every variable $X$ of $V$ into the universe $U$ of $I$. 
- It associates, for each variable, a value in the domain.

# Model of F
Given a signature Σ, an interpretation I and a formula F:
- We say that $I$ ___model__ of_ F or $I$ _satisfies_ F, written $I \models F$ when: ==$I, η \models F$ for every variable valuation η==. 
	- $I \models F$ means that regardless of the evaluation of the variables ($\eta$) the formula $F$ is true in $I$.
- $I$ _a model of theory_ T when $I$ is a model of each formula in T

Sentence $S$ could be:
- ___valid___: if it's satisfied by every interpretation, i.e. $I \models S$ for every $I$.
- ___satisfiable___: satisfied by some interpretations, i.e. $I \models S$ for some $I$. 
- ___falsifaible___: not satisfied by some interpretation, i.e. $I \not\models S$ for some $I$.
- ___unsatisfiable___: not satisfied by any interpretation, i.e. $I \not\models S$ for every $I$.

# Logical consequence
A sentence $T_1$ is a logical consequence of a sentence $T_2$, written $T_2 \models T_1$, if every model of $T_2$ is also a model of $T_1$, i.e. $I \models T_2$ implies $I \models T_1$. 

>[!Theorem]
> It is undecidable whether a first order logic formula F is true under alla possible interpretations.

# Completeness of FOL

### Godel completeness 
$$
 \models F \Longrightarrow \ \vdash F
$$
With "$\vdash$" we intend the symbol for derivation, or deduction/natural deduction. 
In a more general form:
$$Γ \models F \iff Γ \vdash F$$
>[!INFO]
>It is undecidable whether a first order logic formula is provable (or true under all possible interpretations).

We can also build a small arithmentic system using FOL, by which we can establish that:
It is undecidable whether an arithmetical formula is true.
